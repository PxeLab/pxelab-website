**相关文档**: [仪表盘](dashboard.md) | [服务配置](services.md) | [设置](settings.md)

## 侧边栏结构

```
概览
├─ 仪表板（/）

基础配置
├─ 服务配置 ▸（二级子导航）
│   ├─ DHCP（/services/dhcp）
│   ├─ DNS（/services/dns）
│   ├─ NFS（/services/nfs）
│   ├─ TFTP（/services/tftp）
│   ├─ 引导选项（/boot-settings）
│   └─ OS 安装目录（/netboot-catalog）
├─ 文件管理（/files）
├─ 引导菜单（/profiles）
├─ 应答模板（/answer-templates）
└─ 系统镜像（/os-images）

管理
├─ 主机管理（/hosts → /hosts/:id）
├─ 访问控制（/access-control）
├─ 初始化脚本（/scripts）
├─ 安装任务（/install-tasks）
├─ 带外管理（/bmc）
├─ 唤醒管理（/wol）
├─ 网络诊断（/network）
└─ Hub（模板市场）

监控
├─ 事件日志（/events）
├─ 审计日志（/audit-logs）
└─ 实时日志（/logs）

底部
└─ 设置（设置弹窗）
```

## 逐页介绍

### 概览

| 页面 | 入口 | 做什么 | 详细 |
|------|------|--------|------|
| **仪表板** | 概览 → 仪表板 | 全局状态：统计卡片、服务状态、流量图表、最近事件、在线主机 | [仪表盘](dashboard.md) |

### 基础配置

| 页面 | 入口 | 做什么 | 详细 |
|------|------|--------|------|
| **服务配置** | 基础配置 → 服务配置 | 六个子页统一管理网络服务：DHCP（接口/子网/租约/预留）、DNS、NFS、TFTP、引导选项、OS 安装目录 | [服务配置](services.md) |
| **文件管理** | 基础配置 → 文件管理 | 引导文件的上传、删除与浏览 | [文件管理](files.md) |
| **引导菜单** | 基础配置 → 引导菜单 | Profile（引导配置）管理、脚本版本控制、按主机绑定引导 | [引导菜单配置](boot-config.md) |
| **应答模板** | 基础配置 → 应答模板 | 自动化安装应答文件：预设/自定义模板、版本管理与验证 | [应答文件模板](answer-templates.md) |
| **系统镜像** | 基础配置 → 系统镜像 | ISO 上传、导入、挂载、解压与文件浏览 | [OS 镜像管理](os-images.md) |

## 顶栏功能

### 服务状态下拉

顶栏右侧的服务状态指示器，点击展开：

- 各服务运行状态（运行中 / 已停止 / 错误）与端口
- 每个服务可单独启动 / 停止 / 重启，或一键全部操作
- 5 秒自动轮询刷新

### 通知中心

铃铛图标：实时系统通知与历史通知。

### 搜索 / 命令面板（⌘K / Ctrl+K）

- 快速跳转到任意页面
- 显示最近访问页面
- 搜索功能与设置项

### 语言与主题

- 中 / 英文一键切换
- 亮色 / 暗色 / 跟随系统三态主题，主色与圆角可调
