# 网络诊断

> 内置 Ping 与 Traceroute：不离开 Web 界面排查客户端与服务器之间的连通性问题。

**相关文档**: [故障排查](../troubleshooting.md) | [主机管理](host-management.md)

---

## 什么时候用

- 客户端**引导失败**，怀疑网络不通 → Ping 目标，看丢包
- 多网段环境路由不通 → Traceroute 看断在哪一跳

入口：**管理 → 网络诊断**（`/network`），两个 Tab。

## Ping

- 输入目标主机（IP 或主机名）
- 参数：次数、包大小、TTL、间隔、超时、是否持续
- **流式输出**：实时显示每个包的响应
- **统计摘要**：发送/接收/丢失数、RTT 最小/平均/最大
- 可选择出口接口（多网卡环境指定从哪个接口发）

## Traceroute

- 输入目标主机
- **流式输出**：逐跳显示路由路径
- 每跳：序号、主机名、IP、各探测时间
- 可选择出口接口

## 排查示例

| 现象 | 诊断步骤 |
|------|---------|
| 客户端拿不到 IP | Ping 客户端 IP（若已知）；Ping 网关确认链路 |
| 引导到一半卡住 | Traceroute 到 PxeLab 服务器，确认路径与延迟 |
| 多 VLAN 不互通 | Traceroute 观察跨段路径，定位未放行的交换机 |
