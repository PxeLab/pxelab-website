# WOL 网络唤醒

> 通过网络发送魔术包，远程唤醒**关机但插电**的机器。与 BMC 的区别：WOL 不需要带外管理口，但要求网卡支持 WOL 且主板开启了 Wake-on-LAN。

**相关文档**: [主机管理](host-management.md) | [BMC 带外管理](bmc.md)

---

## 什么时候用

- 早上到机房前先把**一批机器唤醒** → 批量唤醒 / 定时唤醒
- 想**每周固定时间**唤醒一批机器 → 定时调度

入口：**管理 → 唤醒管理**（`/wol`）。

## 任务 1：单台唤醒

输入 MAC 地址 + 广播地址，点击唤醒——向该 MAC 发送魔术包。目标机器关机状态（S5）下，只要网卡通电即可被唤醒。

## 任务 2：批量唤醒

从主机列表勾选多台主机 → 批量唤醒。

## 任务 3：定时调度

- **创建定时任务**：指定 MAC + 唤醒时间，支持一次性或周期性（如每周一 8:00）
- **任务列表**：查看、删除定时任务

## 任务 4：查看历史

唤醒历史记录：时间、MAC、广播地址、状态——确认唤醒是否成功送达。

## 提示

- 目标机器**必须插着电源**且网卡支持 WOL（BIOS/固件中开启 Wake-on-LAN）
- 广播地址选错会导致魔术包送不到目标网段——默认用本机接口的广播地址
