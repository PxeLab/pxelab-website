# BMC 带外管理

> 通过 IPMI 远程控制服务器的电源——不依赖操作系统是否存活，服务器死机也能开/关/重启。

**相关文档**: [主机管理](host-management.md) | [WOL 网络唤醒](wol.md)

---

## 什么时候用

- 服务器**死机/无响应**，需要强制重启 → BMC 电源操作
- 机房**批量开机/关机**（几十台）→ 批量操作
- 设置服务器**下次从 PXE 启动** → 启动设备设置

入口：**管理 → 带外管理**（`/bmc`）。

## 任务 1：登记 BMC 配置

三种方式：

- **手动添加**：填写 BMC 地址、用户名、密码
- **CSV 批量导入**：上传 CSV（MAC/主机 + BMC 地址/账号）
- **探测**：自动发现网络中的 BMC 设备

> 前提：BMC 管理口与 PxeLab 网络可达（通常走带外管理网段）。

## 任务 2：电源操作

- **单台**：列表行内 开机 / 关机 / 重启 / 查询状态
- **批量**：勾选多台 → 批量开机 / 关机 / 重启 / 查询状态
- **刷新状态**：重新查询各设备的 BMC 连接状态

## 任务 3：设置启动设备

设置某台服务器**下次启动**从 PXE / 磁盘 / BIOS 启动——配合 PxeLab 引导：设成 PXE → 重启 → 走网络引导装系统；装完设回磁盘。

## 提示

- 操作前确认 BMC 账号有对应权限（部分 IPMI 限制远程关机）
- 批量操作前先用「查询状态」确认设备在线，避免对已关机设备误操作
