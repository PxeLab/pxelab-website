# 安装任务

> 为网络安装建「工单」：指定哪台机器装什么系统、用哪份应答文件，并跟踪进度。

**相关文档**: [应答文件模板](answer-templates.md) | [网络启动目录](netboot.md) | [OS 镜像管理](os-images.md)

---

## 什么时候用

- 批量装机时**跟踪每一台**的进度 → 任务列表
- 配合应答模板实现**无人值守安装** → 创建任务时选模板
- 取消或调整装机计划 → 编辑/删除任务

入口：**管理 → 安装任务**（`/install-tasks`）。

## 任务 1：创建安装任务

点击「新建任务」，选择：

- **发行版与版本**（如 Ubuntu → 22.04）
- **架构**
- **目标主机**（从主机列表选择）
- **应答文件模板**（可选；选了则无人值守）

## 任务 2：跟踪状态

任务列表展示每台机器的安装状态与进度；装机完成后状态更新，可核对结果。

## 任务 3：管理任务

- **编辑**：修改任务参数（如换应答模板）
- **删除**：取消任务
