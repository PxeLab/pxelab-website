# 访问控制

> 按 MAC 地址控制哪些设备能接入网络引导体系。黑白名单在 DHCP 分配时生效。

**相关文档**: [DHCP 配置](dhcp.md) | [主机管理](host-management.md)

---

## 什么时候用

- 只允许**登记过的设备**接入 → 白名单
- 封禁**特定设备**（报废、可疑）→ 黑名单
- 想先**观察**哪些设备在网络上 → 未授权设备列表

入口：**管理 → 访问控制**（`/access-control`）。

## 规则逻辑

| 列表 | 行为 | 适用场景 |
|------|------|---------|
| **白名单** | 仅列表中的 MAC 可获取 IP | 严格控制接入设备 |
| **黑名单** | 列表中的 MAC 被拒绝 | 封禁特定设备 |
| **未授权设备** | 不在任何名单中的设备 | 监控和审计，可一键加入名单 |

> 子网级还有独立的「子网白名单」（DHCP 配置中）：全局白名单开启时，子网白名单强制启用；子网可单独收紧策略。

## 任务 1：添加黑名单

黑名单 Tab → 添加：填写 MAC 与原因（如「已报废设备」）。之后该设备无法从 DHCP 获取 IP。

## 任务 2：添加白名单

白名单 Tab → 添加：MAC + 子网 + 原因。仅允许名单内设备接入时，开启全局白名单开关。

## 任务 3：处理未授权设备

未授权设备 Tab 列出所有不在名单中的设备：

- **一键加入白名单** — 放行该设备
- **一键加入黑名单** — 封禁该设备
- 删除记录 — 忽略该设备（下次出现还会记录）

## 提示

- 白名单模式下手滑漏加设备会导致其**拿不到 IP**——先加名单再开全局开关
- 访问控制与[主机管理](host-management.md)配合：登记主机时可顺手把 MAC 加入白名单
