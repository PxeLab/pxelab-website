# 网络启动目录（OS 安装目录）

> 内置 64+ 主流发行版的安装菜单：客户端引导后选一个系统就能装。无需准备 ISO，目录里的条目直接下载引导。

**相关文档**: [引导菜单配置](boot-config.md) | [OS 镜像管理](os-images.md) | [应答文件模板](answer-templates.md)

---

## 什么时候用

- 想**开箱即用批量装机**（Ubuntu、Debian、CentOS、Windows…）→ 确认目录启用，客户端引导即可选择
- 只想显示**部分系统**、或调整菜单顺序 → 分组管理
- 某个发行版需要**自定义内核参数** → 覆盖层
- 重复引导慢 → 开启本地缓存

入口：**基础配置 → 服务配置 → OS 安装目录**；或侧边栏底部 **设置 → Netboot**（全局开关）。

## 任务 1：确认目录已启用

OS 安装目录页，确认「**启用**」开关已打开（默认开启）。启用后，客户端引导菜单会出现 **[OS] Netboot OS Install Catalog** 入口。

## 任务 2：分组管理

目录按分组组织（Linux Distributions、Windows、System Tools、Live CDs 等 10 组），分组从已启用的发行版自动派生；分组的启用状态、显示标题与顺序通过 `config.yaml` 的 `catalog_display.groups` 配置：

- **启用/禁用分组** — 不需要的系统整组隐藏
- **自定义标题** — 改显示名称
- **调整顺序** — 通过 `order` 字段排序（数值越小越靠前）

## 任务 3：覆盖层（per-发行版定制）

为特定发行版定制引导参数，不影响默认配置：

- 入口：OS 安装目录页 → 发行版 → 覆盖配置（或 API `PUT /api/v1/netboot/overlays/{distro}`）
- 可设置：镜像源（Mirror）、本地基础路径（LocalBase）、内核参数（KernelParams）、版本覆盖
- 用途：内网镜像源加速、为特定发行版追加引导参数

## 任务 4：本地缓存

设置 → Netboot → **本地缓存**（默认开启）：

- 下载过的引导文件落盘，重复引导不再从外网下载
- 页面实时显示缓存路径、文件数与磁盘占用
- 缓存统计 API：`GET /api/v1/netboot/cache-stats`
