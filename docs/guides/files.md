# 文件管理

> 引导文件目录的可视化管理：上传、删除、浏览。引导文件是客户端 PXE 引导的第一步，缺失会导致「拿到 IP 但引导失败」。

**相关文档**: [TFTP 服务](../reference/tftp.md) | [服务配置](services.md)

---

## 什么时候用

- 客户端**引导失败，提示找不到引导文件** → 来确认/上传对应文件
- 想**自定义 NBP**（自编译 iPXE 等）→ 上传到引导目录
- 检查文件完整性 → 看 MD5 与大小

入口：**基础配置 → 文件管理**（`/files`）。

## 任务 1：上传文件

点击「**上传文件**」，选择本地文件上传。上传后立即出现在文件列表，TFTP/HTTP 即可访问。

常见引导文件与用途：

| 文件 | 用途 |
|------|------|
| `undionly.kpxe` / `ipxe.pxe` | BIOS x86 的 iPXE NBP |
| `ipxe.efi` / `ipxe32.efi` / `ipxe-arm64.efi` | UEFI 各架构 iPXE NBP |
| `pxelinux.0` / `pxelinux.efi` | PXELinux 引导 |
| `grubx64.efi` / `grubaa64.efi` | GRUB2 引导 |

> 各客户端架构对应哪个引导文件，在 **服务配置 → 引导选项** 的架构映射表中查看；缺失时页面会提示上传。

## 任务 2：删除文件

列表行内删除。删除前确认没有客户端还在用它——删除正在使用的 NBP 会导致引导失败。

## 任务 3：浏览引导目录

文件列表即引导文件根目录的可视化浏览，支持查看目录结构。上传的 ISO 等大文件建议走 [OS 镜像管理](os-images.md)（支持挂载）。
