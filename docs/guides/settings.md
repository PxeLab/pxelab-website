# 设置

> 侧边栏底部「设置」弹窗，5 个分区管全局配置。多数配置即时生效或保存后热重载。

**相关文档**: [配置文件参考](../reference/config-file.md) | [日志配置](../reference/logging.md) | [网络启动目录](netboot.md)

---

## 通用设置

| 配置项 | 说明 |
|--------|------|
| 服务器名称 | 界面与服务显示名 |
| 监听地址 | 如 `:8080` |
| 数据目录 | PxeLab 数据存放位置 |
| API Token | 远程 API 访问令牌（复制/重新生成） |
| 每页条数 | 列表页默认分页大小 |

## 引导菜单

默认引导菜单配置（客户端未绑定 Profile 且未启用 OS 目录跳转时显示）：

- 菜单标题（默认 `PxeLab Boot Menu`）
- 超时时间（0 = 不自动选择）
- 默认菜单条目：添加/删除/排序，配置类型与参数

## Netboot

- **启用/禁用** OS 安装目录
- **安装目录跳转**配置（客户端无 Profile 时是否直接跳转目录）
- **目录菜单结构**：分组排序、启用/禁用、标题编辑
- **自定义 iPXE 脚本**：完全替代可视化配置（高级）
- **本地缓存**开关与缓存统计
- **失败提示**开关

## 服务自启动

各服务（HTTP/DHCP/TFTP/DNS/NFS）的自动启动开关——**即时生效**，无需保存。服务器重启后按此配置决定哪些服务自动拉起。

## 日志管理

- 日志级别（debug / info / warn / error）
- 日志文件路径
- **轮转**：单文件最大体积、保留份数、保留天数、gzip 压缩
- 清理检查间隔

日志轮转与排查的详细说明见[日志配置](../reference/logging.md)。
