# 设置

> 侧边栏底部「设置」弹窗，6 个分区管全局配置：通用设置、引导菜单、Netboot、服务自启动、日志管理、关于。多数配置即时生效或保存后热重载。

**相关文档**: [配置文件参考](../reference/config-file.md) | [日志配置](../reference/logging.md) | [网络启动目录](netboot.md)

---

## 通用设置

| 配置项 | 说明 |
|--------|------|
| 服务器名称 | 界面与服务显示名 |
| 日志级别 | debug / info / warn / error |
| 监听地址 | 如 `:8080` |
| 数据目录 | PxeLab 数据存放位置 |
| API Token | 远程 API 访问令牌（复制/重新生成） |
| 每页条数 | 列表页默认分页大小 |

## 引导菜单

默认引导菜单配置（客户端未绑定 Profile 且未启用 OS 目录跳转时显示）：

- **自定义 iPXE 脚本**：填写后完全替代所有可视化配置（高级）
- **超时时间**（0 = 不自动选择）
- **列出全部 Profiles**：默认菜单展示所有 Profile（否则仅展示默认 Profile 的引导项）

> 菜单项本身在默认 Profile 中管理（**基础配置 → 引导菜单**），标题固定为 `PxeLab Boot Menu`。

## Netboot

- **启用/禁用** OS 安装目录
- **HTTPS 代理**：目录下载走本地 HTTPS 代理
- **本地缓存**开关与缓存统计（文件数 / 占用空间）
- **目录标题**：OS 安装目录菜单的显示标题
- **安装目录跳转**配置（客户端无 Profile 时是否直接跳转目录，含目标地址与前置脚本）

> 分组排序、分组启用/禁用通过 `config.yaml` 的 `catalog_display.groups` 配置，界面仅可编辑标题。

## 服务自启动

各服务（HTTP/DHCP/TFTP/DNS/NFS）的自动启动开关——**即时生效**，无需保存。服务器重启后按此配置决定哪些服务自动拉起。

## 日志管理

- 日志文件路径（只读展示）
- **轮转**：单文件最大体积、保留份数、保留天数、gzip 压缩
- 清理检查间隔
- **磁盘用量**：当前日志文件列表与总占用，可一键**立即清理**

日志轮转与排查的详细说明见[日志配置](../reference/logging.md)。
