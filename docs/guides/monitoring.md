# 监控

> 三个页面看穿系统：事件日志（发生了什么）、审计日志（谁改了什么）、实时日志（服务在报什么）。

**相关文档**: [日志配置](../reference/logging.md) | [仪表盘](dashboard.md) | [网络诊断](network-diagnostics.md)

---

## 什么时候用

- 客户端**引导过程排查** → 事件日志（看 DHCP/TFTP/HTTP/BOOT 事件流）
- 配置**被谁改了** → 审计日志
- 服务**报错排查** → 实时日志（按服务过滤）

## 事件日志（监控 → 事件日志）

- **SSE 实时流**：新事件即时推送，支持暂停/恢复
- **类型过滤**：全部 / DHCP / TFTP / HTTP / BOOT / WOL / IPMI
- 事件列表：时间、类型（彩色标签）、MAC、消息
- 支持全屏查看

典型用法：客户端引导失败时，开事件日志过滤 `DHCP` + `BOOT`，看它在哪一步断了。

## 审计日志（监控 → 审计日志）

所有配置变更的追踪记录：

- 列：时间、操作类型（创建/更新/删除）、资源类型、资源名称、操作者 IP、变更详情
- 变更详情示例：`名称: A→B; 架构: x86_64→arm64`

用于多人协作的变更审计与回溯。

## 实时日志（监控 → 实时日志）

- **SSE 实时流**，多面板，按服务过滤，不同服务不同颜色
- **历史日志文件**列表与**磁盘占用**统计
- **手动清理**旧日志

日志级别、轮转等配置见[日志配置](../reference/logging.md)。
