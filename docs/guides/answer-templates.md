# 应答文件模板

> 预填安装程序的问答，实现**无人值守安装**：客户端引导后全自动装完，不需要人守在屏幕前点向导。

**相关文档**: [安装任务](install-tasks.md) | [网络启动目录](netboot.md) | [引导菜单配置](boot-config.md)

---

## 什么时候用

- 批量装机，不想逐台点安装向导 → 应答文件 + 安装任务
- 装机参数（分区、时区、软件源、预置用户）要**标准化** → 模板 + 变量

入口：**基础配置 → 应答模板**（`/answer-templates`）。

## 应答文件类型

| 类型 | 适用发行版 |
|------|-----------|
| `preseed` | Debian / Ubuntu（旧版） |
| `subiquity` | Ubuntu（新版安装器） |
| `kickstart` | CentOS / RHEL / Fedora |
| `autoyast` | openSUSE |
| `autounattend` | Windows |

## 任务 1：创建模板

点击「新建」：选择**预设模板**（常见发行版的开箱模板）或从空白创建，填写名称、类型、内容。

## 任务 2：使用变量

模板内容支持变量替换（如主机名、MAC、IP 等运行时信息），让一份模板适配多台机器。变量清单在创建/编辑表单中查看。

## 任务 3：预览与验证

保存前使用「**预览**」生成最终应答文件（变量替换后）；「**验证**」检查语法与格式，错误会给出提示，避免装机中途失败。

## 任务 4：版本管理

每次修改自动保存历史版本，支持对比与回滚——与 Profile 的版本管理一致。

## 与安装任务配合

在**安装任务**中创建任务时选择该模板，装机过程即按应答文件无人值守执行。详见 [安装任务](install-tasks.md)。
