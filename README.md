# PxeLab Website

The official website and design demos for [PxeLab](https://github.com/PxeLab/pxelab).

## Contents

- `index.html` — Main landing page
- `fonts/` — Local fonts (Inter, JetBrains Mono)
- `demos/` — Alternative design explorations

## Development

This is currently a static HTML site. Open `index.html` directly in a browser, or serve it with any static file server:

```bash
npx serve .
```
